# Determine altitude correction factor for haemoglobin

Determine altitude correction factor for haemoglobin

## Usage

``` r
get_altitude_correction(alt = NULL)
```

## Arguments

- alt:

  Altitude, in metres, above sea level

## Value

A numeric value or numeric vector of correction factor/s for haemoglobin
based on altitude
